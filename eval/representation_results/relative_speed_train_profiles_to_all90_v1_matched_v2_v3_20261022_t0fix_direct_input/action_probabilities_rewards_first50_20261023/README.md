# Action probabilities and recorded step rewards, first 50 steps

Evaluation rewards, post-observation recurrent states h_t, is_t0, and executed allocation actions were saved. Full policy action probability vectors and sampled joint movement/allocation actions were not in the original HDF5 logs. These plots reconstruct probabilities from the final frozen policy actor head and the actual saved h_t; rewards are read directly from the original evaluation logs. No RL or probe fitting and no new environment trajectories. Reconstructed probabilities may differ from the original unsaved GPU computation at floating-point rounding precision. Six original frozen Flax network checks cover all three protocols and both conditions.

The plotted 50 decisions are t=0..49. Each distribution is conditional on the observation at t (saved post-observation h_t); its paired reward is the original reward from executing the corresponding action at t. Rewards are per-step, not cumulative returns.

Exactly the latest decoding cohort: v1_matched/v2/v3, multi-partner and no-influence RNNs, seeds 1–5, all 90 unequal ordered delay pairs. Four held-out repetition IDs 1,9,14,15 (zero-based) per profile/seed. Single-partner policies are absent because they are absent from that decoding study. Every selected episode remains active throughout the first50 steps.

Histogram: one stacked bar per timestep, 15 discrete joint action bins; action ID=3*movement+allocation. R/B request the EGO's red/blue role; when influence applies the partner takes the complementary goal. NONE is a reserved code in v2/v3 and has zero probability. Movement directions are absolute grid directions. These are averaged policy probabilities, not a histogram of sampled action counts.

Masks: v1 at round t0 allows only Stay/R and Stay/B, and later only movement/None. v2 at t0 forces the supplied random initial assignment; v3 influence permits both Stay/R and Stay/B, whereas v3 no-influence forces the supplied assignment. Later v2/v3 allow movement×R/B. Supplied t0 allocations are recovered from their recorded executed allocation, which must equal the forced default. Original frozen network masks were checked independently.

Average probabilities and rewards over the four episodes within each profile and seed, then average five policy seeds. Category averages give each profile equal weight within each seed before averaging seeds. Categories contain 24 green, 18 blue, 42 yellow, and 6 pink profiles. There is no smoothing or averaging across time. Reward bands are 95% percentile bootstrap intervals over five seed means (10,000 draws, RNG30000). Histogram uncertainty is not displayed.

Files: per_profile/ contains90 individual PNGs, each showing all three experiments and both conditions. action_probabilities_rewards_all_profiles.pdf has the same90 pages. The category_averages_multi_partner/no_influence PNG/PDF files compare all four categories across experiments. profile_summary.csv.gz and category_summary.csv.gz contain all15 joint probabilities, movement/allocation marginals, rewards and intervals. Per-seed NPZ summaries preserve seeds; policies/ preserves episode-level reconstructed probabilities and original rewards. action_key.csv maps every action ID. completion_audit.json records checks.
