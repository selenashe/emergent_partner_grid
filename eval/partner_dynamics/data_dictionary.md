# Data dictionary and time conventions

Historical HDF5 arrays have episode, environment-step and (where applicable)
feature axes. The first `dones=True` transition is included; later scan padding
is excluded even when it contains finite hidden states and more round endings.
Episodes must have 20 ordered round endings. Capability and profile ordering are
validated on valid steps against the authoritative populations.

| Field | Meaning at recorded step t |
| --- | --- |
| `hidden_state[t]` | Carry after consuming observation t; produced action t. |
| `capability[t]` | Ground-truth fixed partner delays; analysis labels only. |
| `layout_idx[t]`, `round_idx[t]` | The pre-transition round and physical layout. |
| `round_time[t]` | Post-transition elapsed time of that pre-transition round. |
| `round_done[t]` | Action t completed/timed out the pre-transition round. |
| `dones[t]` | Action t completed the entire 20-round partner episode. |
| `success[t]` | Success flag for that transition; round metrics use round endings. |
| `rewards[t]` | Reward from action t, not from observation t. |
| `is_t0[t]` | Observation t was the new-round start. |
| `ego_alloc_action[t]` | Recorded effective request/default, distinct from sampled flat action. |
| `partner_assignment[t]`, `partner_goal[t]` | Effective assignment/goal after the request, before any next-round reset. |
| `assignment_changed[t]` | Effective switch at transition t, where available in v2. |
| `ego_request_changed[t]` | Request change at transition t, where available in v2. |

A real round boundary is `(hidden_state[end], hidden_state[end+1])` within one
partner episode. Memory is retained there. This is distinct from episode reset,
where the original GRU resets its carry. Geometry samples start, midpoint and
end at actual step indices, not interpolated time. Identical start/mid/end
indices can occur for very short rounds; their statistical unit remains the
whole episode.

## New instrumented capture

`capture.h5` is a new dataset, not a reconstruction of the old files. It retains
fixed-width arrays with a separate `valid` mask. `history_complete` marks the
end of a four-round diagnostic history; it is not a true environment episode
termination and must not be substituted for `dones`.

| Field/group | Meaning |
| --- | --- |
| `observation/*` | Raw leaves actually presented to the policy; no capability label is fed to it. |
| `encoded_input[t]` | Output of the original policy LayerNorm, the actual GRU input at t. |
| `carry_before[t]` | Carry before consuming observation t. |
| `hidden_state[t]` | Carry after consuming observation t. |
| `reset_flag[t]` | Original GRU reset flag; false within these four-round histories. |
| `probabilities`, `logits`, `value` | Original masked categorical outputs and critic prediction. Illegal logits are `-inf` by design. |
| `flat_action`, `action_key` | Sampled flat action and the original batch-shaped categorical key. |
| `step_key` | Per-slot environment PRNG key for this transition. |
| `pre_state/*`, `post_state/*` | All original simulator state leaves, including position, move counter, capability and layout schedule. |
| `info/*` | Original transition metadata, including decoded requests and effective move fields. |
| `history_final_carry` | Carry before a subsequent physically valid new-round observation. |
| `capability_profile`, `repetition` | Evaluator labels and independent history-group IDs. |

For post-observation states, dynamics pair `(h[t], encoded_input[t+1]) -> h[t+1]`.
Each delay window is constructed inside a contiguous real round. No fabricated
transitions join different episodes/round segments. Genuine boundary updates
are separately available in the audit and raw captures.

Observable movement events compare the partner channel of consecutive input
grids within a real round. The movement at observation t was generated by the
previous transition. Goal-conditioned intervals use its recorded actual goal
and exclude intervening goal changes. These are evidence-exposure diagnostics,
not a demonstrated agent belief or Bayesian posterior. Collisions and switches
can prevent observed cadence from equaling the partner's intrinsic delay.

## Splits and interventions

Historical analysis: deterministic 12 train / 4 validation / 4 test repetitions
per profile, all 20 rounds grouped together. Target layout groups use SHA256 of
the layout index modulo five. Prior histories can overlap target layouts.

Targeted capture: repetitions 0–1 discovery, 2 validation, 3 test, separately for
each of six profiles. Candidate subspaces never use intervention outcomes.
Each recipient's environment state and PRNG state are identical across arms;
the true partner is retained. Open-loop replay uses identical baseline inputs
and measures network response; its outputs are not environment reward.

v1's first learned allocation is t=0. v2's supplied t=0 allocation is forced;
its first learned allocation is t=1. Because all v2 arms have the same physical
state and forced t=0 action, their t=1 observation is identical. The original
`open_loop_probability_l1` in early collection summaries refers to t=0 and is
therefore zero in v2. Use `open_loop_outcomes.json` for the first learned decision.
